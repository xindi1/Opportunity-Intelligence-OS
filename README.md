Opportunity Intelligence OS v4

What changed:
- Robust Mass Import tab
- Accepts JSON arrays
- Accepts wrapper objects with records/data/items/problems/opportunities/results arrays
- File import now previews records before adding
- Paste JSON import added as fallback for iPhone/Safari
- Duplicate detection by problem name
- Clear import validation and error reporting
- Keeps v3 data by migrating from old localStorage keys
- 24-hour timestamps retained
- Light/dark mode retained
- PWA icons and offline service worker retained

Recommended iPhone import workflow:
1. Open Opportunity OS.
2. Tap Import in the header or Mass Import tab.
3. Choose the JSON file.
4. Confirm the validation message.
5. Tap Import Pasted JSON if needed after preview.
